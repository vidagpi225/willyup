Chưa cấu hình Supabase. Trang này cần Supabase mới đăng nhập thật được. Hãy mở chính file index.html này trên GitHub, tìm SUPABASE_ANON_KEY, dán key Publishable (bắt đầu bằng sb_publishable_) vào thay cho YOUR-ANON-KEY, rồi Commit lại. File config.js riêng không còn được dùng trong bản 1 file này.

Quên mật khẩu

Nhập email đã đăng ký, Supabase sẽ gửi mail đặt lại mật khẩu. Kiểm tra cả Spam.

Đặt mật khẩu mới

Bạn vừa bấm link trong mail đặt lại mật khẩu. Nhập mật khẩu mới dưới đây.

Chống bot ở đây có 2 lớp: câu tính do trình duyệt tạo + khóa tạm sau 5 lần sai. Đây không thay thế CAPTCHA thật. Để chống bot thật, hãy bật hCaptcha / Cloudflare Turnstile trong Supabase Dashboard theo README.md bước 4.
